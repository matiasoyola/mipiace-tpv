Comando para pegar en el Terminal del VPS (hPanel → VPS → Administrar → Terminal):

```sql
docker exec mipiacetpv-postgres psql -U mipiacetpv -d mipiacetpv -c "
SELECT t.name AS tenant,
       COUNT(*) FILTER (WHERE tk.paid_at::date = CURRENT_DATE) AS tickets_hoy,
       MAX(tk.paid_at) AS ultimo_cobro
FROM tenants t
JOIN tickets tk ON tk.tenant_id = t.id
WHERE tk.paid_at IS NOT NULL
  AND tk.status NOT IN ('TEST','VOIDED')
  AND tk.paid_at > '2026-08-19 12:00:00'
GROUP BY t.name
ORDER BY ultimo_cobro DESC;"
```
